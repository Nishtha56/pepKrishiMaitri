🌾 Krishi Maitri – Farmer’s Friend

Krishi Maitri is a minor academic web project aimed at bridging the gap between modern technology and agricultural knowledge.
It provides farmers and users connected to agriculture with clear, structured, and language-accessible guidance using data and AI.

❓ Problem Statement

Although India is an agricultural country, farming knowledge is no longer always passed down through generations.
At the same time, while smartphones are widely used, reliable and understandable farming information is still difficult to access, especially due to language barriers and scattered data sources.

Krishi Maitri addresses this problem by bringing essential agricultural information into a single, easy-to-use platform.

✨ Features

🌦️ Weather Module

Location-based weather updates

Dynamic changes when location is updated

AI-based actionable recommendations

📊 Minimum Support Price (MSP)

Government-backed MSP data from the last 10 years

Data-only module to maintain authenticity

🏛️ Government Schemes

Important farmer schemes in one place

AI-generated summaries for easy understanding

🌱 Crop Guidance

Crop-specific fertilizer and irrigation guidance

AI-enhanced suggestions

🤖 AI Assistant

Farming-related query support

Responds in the user’s selected language

🌍 Language Support

English ↔ Hindi language switch

AI responses adapt to selected language

🛠️ Tech Stack

Frontend: React + TypeScript

Styling: Tailwind CSS, shadcn-ui

Build Tool: Vite

Architecture: Component-based UI

🚀 Getting Started
Prerequisites

Node.js

npm

Installation
git clone <YOUR_GIT_REPOSITORY_URL>
cd krishi-maitri
npm install
cp .env.example .env
cp backend/.env.example backend/.env
npm run dev

Environment files:
- Frontend: .env
- Backend: backend/.env

For Docker Compose, the container environment values are already populated from the compose file, but you can still override them by editing the relevant environment section.
